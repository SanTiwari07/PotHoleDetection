# Accessibility Statement

IPDS aims to be usable by as many people as possible, including those using assistive technologies.

## Commitment

We aim for the project website ([index.html](index.html)) and documentation to follow the [WCAG 2.1](https://www.w3.org/TR/WCAG21/) Level AA guidelines where practical.

## Supported environments

- Website: current versions of Chrome, Firefox, Safari, and Edge, with keyboard navigation and screen readers
- Documentation: plain Markdown, readable on GitHub and in any text editor

## Known limitations

- Demo videos and hardware photographs may lack complete captions or text descriptions.
- Some diagrams in `Diagrams/` convey information visually; the README describes the same architecture in text.
- The hardware prototype's alerts (buzzer/LED) are not designed for users with hearing or vision impairments in isolation.

## Reporting barriers

If you hit an accessibility barrier, please [open an issue](https://github.com/SanTiwari07/PotHoleDetection/issues/new/choose) or email sanskartiwari.smt@gmail.com. We will respond within 14 days and work on a fix.
